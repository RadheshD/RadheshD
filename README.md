## 🚀 Flagship Builds

<details open>
<summary><b>⚡&nbsp; AutoExtract — Universal Document Intelligence & Invoice Extraction System</b></summary>
<br/>

> A 6-layer document processing engine that ingests invoices, receipts, travel tickets, scanned PDFs, and email attachments — combining hybrid OCR, rule-based normalization, and LLM-powered semantic extraction. Started as a PyQt5 desktop tool, now a full FastAPI + Next.js web platform.

| | |
|:--|:--|
| 🧱 **Pipeline** | Direct text extraction (pdfplumber) → OCR fallback (PyMuPDF + Tesseract/PaddleOCR) → structural layout parsing → semantic regex → specialized extractors (flight/hotel/tax) → LLM context parser (OpenRouter/Gemini) |
| ⚙️ **Backend** | FastAPI · Uvicorn · SQLite (Alembic migrations) |
| ⚙️ **Frontend** | Next.js (App Router, Turbopack) · React · TailwindCSS · TanStack Query · TypeScript (strict) |
| 🔐 **Ingestion** | Gmail OAuth 2.0 + IMAP polling |
| 🧠 **Intelligence Layer** | Natural-language invoice search, human-in-the-loop review queue, self-learning correction database, vendor pattern tracking |
| 🛡️ **Duplicate Protection** | Reference-hierarchy matching: Invoice No → Receipt No → Order ID → Booking ID → PNR |
| 📊 **Verified Results** | 100% pass on end-to-end test suite · 82% extraction accuracy across 25 complex document variants · 12/12 REST endpoints operational · 0 TypeScript errors |
| 🔗 **Repo** | [github.com/Sriainfotech/autoextract](https://github.com/Sriainfotech/autoextract) |

</details>

<details open>
<summary><b>👁️&nbsp; FaceAttend AI — Real-Time Facial Recognition Attendance Kiosk</b></summary>
<br/>

> A fully on-premise, zero-cloud-dependency facial recognition kiosk that replaces fingerprint scanners and swipe cards — with active liveness detection, adaptive lighting correction, and instant in-memory biometric matching.

| | |
|:--|:--|
| 🧱 **Vision Engine** | OpenCV + `face_recognition` (dlib) — 128-D face embeddings cached in-memory (pickle) for fast Euclidean-distance matching |
| 🛡️ **Anti-Spoofing** | MiniFASNet (PyTorch) — defeats photo/video/screen presentation attacks via texture & depth analysis |
| 🌓 **Lighting Resilience** | CLAHE adaptive histogram equalization — handles glare, low light, and harsh shadows |
| ⚙️ **Backend** | FastAPI · SQLite + SQLAlchemy · JWT/Bcrypt auth |
| 🖥️ **Kiosk UI** | Vanilla HTML5/CSS3/ES6 · WebRTC live camera streaming · zero-click scan flow |
| 🔄 **Workforce Logic** | Auto CHECK_IN/CHECK_OUT shift toggling with cooldown windows, multi-camera + geofence support |
| 🔐 **Privacy** | 100% on-premise — no cloud dependency, only non-reconstructible vector embeddings retained |
| 🔗 **Repo** | [github.com/RadheshD/Face-Recognition-System](https://github.com/RadheshD/Face-Recognition-System) |

</details>
